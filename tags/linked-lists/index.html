What is a Linked List? Concept: A Dynamic Data Structure A Linked List is a linear data structure, but its elements are not stored contiguously in memory. It is composed of a series of Nodes, where each node contains two parts: Data field: stores the element’s data. Pointer field: stores the memory address of the next node. This structure — discrete memory blocks chained together via pointers — makes linked lists very efficient for insertion and deletion operations. Comparison with Arrays Array Linked List Memory Contiguous Non-contiguous Access Fast — O(1) Slow — O(n) Insert/Delete Slow — O(n) Fast — O(1) Structure: Nodes and Pointers Singly Linked List The simplest type of linked list. Each node has exactly one pointer pointing to its successor node.
